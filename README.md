# 你的 MBTI 是原装的吗 · 出厂检验

一个单文件的人格测试页面：选择 MBTI → 11 道题 → 四维状态 → 五档总体版本 → 四屏可截图的结果。

- 纯前端，无任何依赖，打开 `index.html` 即可使用
- 16 型各自配有原创 SVG 形象，按 NT / NF / SJ / SP 四组配色
- 结果包含封面、四维验货表、清醒洞察、截图配文四屏
- 支持键盘 A/B/C/D 作答、一键复制配文、重新验货

## 另一个测试

## 本地使用

直接用浏览器打开 `index.html`，或起一个静态服务器：

```bash
python -m http.server 8080
```

## 部署

任意静态托管均可（GitHub Pages / Netlify / Vercel），不需要构建步骤。
